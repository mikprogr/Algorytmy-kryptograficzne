# Algorytmy-kryptograficzne

Projekt zawiera program główny, 4 algorytmy oraz przykładowy kod generujący ciąg znaków odpowiadający kluczowi.

Zawartość projektu obejmuje następujące pliki:
Program.cs - program główny
Klucz.cs - przykładowy program do generowania losowego ciągu znaków
Algorytm 3DES.cs - odpowiada za algorytm 3DES
Algorytm AES.cs - odpowiada za algorytm AES
Algorytm MD5.cs - odpowiada za algorytm MD5
Algorytm RSA.cs - odpowiada za algorytm RSA
